# 设计原理

## 为什么用分级目录 + 时间轴？

- **分级目录**：长半衰期知识（概念、决策），稳定。
- **时间轴**：动态状态（计划、执行），可变。  
- 分离两者防止污染，保留历史轨迹。

## 为什么不用纯RAG？

- RAG在运行时检索原始片段 → 不确定性高，一致性无保证。
- 本方案**预先编译**知识 → 确定性、可人工审阅。

## 为什么先人工筛选？

- 当前大模型无法从杂乱长对话中可靠提取高质量知识。
- 人工预筛选保证高信噪比，为编译提供干净输入。

## 与现有工作的关系

- Karpathy Wiki：共享“LLM即编译器”哲学。
- ByteRover：同样使用层级化`.md`文件，但无时间轴。
- MemPalace：空间索引，本方案采用时间+分类索引。
- OpenHuman：自动化记忆树，本方案强调人工可控。

独特贡献：**将时间轴作为一等公民 + 显式冲突演化追踪**。
